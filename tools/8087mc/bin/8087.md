# Intel 8087 microcode explained

The microcode consists of 16-bit words, and there are 1648 words in total.

I will denote individual bits with letters: `ABCDEGHIJKLMNOP` with A being the most significant bit, and P the least significant bit. In mask definitions, an uppercase letter means the bit is set, a lowercase letter means the bit is unset, and a dot `.` means we don't care which one it is.

# Opcodes

## Jumps and calls

Masks:

`Abcd............` Far jump
`AbCd............` Far call
`ABcde...........` Local jump forward
`ABcDE...........` Local jump backward

The following look like local jumps but the addresses turn out to be garbage.

`ABcDe...........` ??
`ABcdE...........` ??

All jumps/calls use `JLKMNO` as the condition for the jump. The `P` bit inverts the condition. `JKLMNop` is an unconditional jump/call. Curiously, `JKLMNoP` is used exactly once - it's the inverse of an unconditional jump/call, meaning "never take this jump/call"?

## Exceptions

`ABCDefghijkl....` Set exception. The bits `MNO` contain the exception index from 0 to 5 in the same order as in the status word, except the bit `O` is inverted. So: 

- 0="denorm"
- 1="invalid"
- 2="overflow"
- 3="division by zero"
- 4="precision"
- 5="underflow"

Maybe `O` is flipped consistently in the microcode?

## Stack manipulation

`aBCDEfghijklmnop` Decrement stack pointer.

`aBCDEfghijklmnOp` Increment stack pointer.
